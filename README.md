# HomeDeck releases

Installers and automatic updates for the **HomeDeck** desktop app for Windows.

- **Download:** get the latest `HomeDeck-Setup-x.y.z.exe` from [Releases](https://github.com/bazzernazz/homedeck-releases/releases/latest).
- **Updates:** once installed, HomeDeck updates itself from here automatically.

The installer isn't code-signed, so Windows shows "Windows protected your PC" the first time. Click **More info → Run anyway**.

This repository only holds installer files. HomeDeck's source code is kept separately.
